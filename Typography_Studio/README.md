# Typography Studio

## 🚀 How to Run

Your app is a Single Page Application (SPA) that needs a web server to work properly.

### Option 1: PowerShell Script (Easiest)
```powershell
.\start-server.ps1
```
Then open: http://localhost:8000/app.html

### Option 2: Python
```bash
python -m http.server 8000
```
Then open: http://localhost:8000/app.html

### Option 3: VS Code Live Server
1. Install "Live Server" extension in VS Code
2. Right-click `app.html`
3. Select "Open with Live Server"

### Option 4: Node.js
```bash
npx http-server
```
Then open: http://localhost:8080/app.html

A professional web-based platform for learning typography principles through interactive tools and exercises. Designed for graphic designers, design students, and typography enthusiasts.

## Overview

Typography Studio provides a comprehensive, hands-on approach to mastering typography. The platform incorporates **Elements of Design**, **Principles of Design**, and **Gestalt Principles** throughout all modules.

## Design Principles Integration

### Elements of Design
- **Line**: Letter strokes, visual flow
- **Shape**: Letter forms, geometric construction
- **Color**: Mood setting, brand identity
- **Texture**: Visual weight, pattern
- **Space**: Negative space, breathing room

### Principles of Design
- **Contrast**: Size, weight, serif vs sans-serif
- **Balance**: Symmetrical and asymmetrical
- **Emphasis**: Focal points, hierarchy
- **Movement**: Eye flow, direction
- **Rhythm**: Repetition, pattern
- **Unity**: Consistency, cohesion
- **Alignment**: Visual structure

### Gestalt Principles
- **Proximity**: Grouping related elements
- **Similarity**: Pattern recognition
- **Closure**: Completing incomplete forms
- **Continuity**: Visual flow
- **Figure-Ground**: Contrast relationships
- **Common Fate**: Directional movement
